# 🛡️ Cyber Log Analyzer

A cybersecurity log monitoring tool that detects brute-force login attacks from authentication logs and provides security insights through a web dashboard.

---

## Features

✅ Log file analysis  
✅ Failed login detection  
✅ Successful login tracking  
✅ Brute force attack detection  
✅ Source IP identification  
✅ Username tracking  
✅ Threat scoring system  
✅ Risk classification  
✅ CSV and JSON reports  
✅ MITRE ATT&CK mapping  
✅ Streamlit security dashboard
